# Day 32 Practice Lab: IPv6 Configuration & Verification

**Part 1: Static IPv6 Configuration**
Configure two routers with IPv6 addresses. Test connectivity between them using ping.

**Part 2: Link-Local Discovery**
Verify that link-local addresses auto-generate. Can you ping using fe80::1%interface notation?

**Part 3: Routing Table Analysis**
Show the IPv6 routing table. Explain what C, L, and connected routes mean.

**Part 4: Troubleshooting**
Given a broken topology where R1 can't reach R2, diagnose the problem using show commands.

**Hints:** Check ipv6 routing enabled, interface IPv6 address status, and neighbor reachability.
