# Day 57: Wireless Networking (802.11)

## Metadata
- **Objective:** Configure wireless LAN access points and security
- **Prerequisites:** Days 1-50
- **Time:** 90 minutes

## Wireless Configuration
SSID, authentication (WPA2/WPA3), encryption, channel assignment.

## Security Modes
- Open (no security)
- WEP (deprecated)
- WPA (pre-shared key)
- WPA2/WPA3 (enterprise)

## Key Concepts
- 802.11a/b/g/n/ac/ax standards
- 2.4 GHz (interference) vs. 5 GHz (range)
- RSSI (signal strength)
- Roaming between APs
